# COVID-19 Dataset – Parquet v2

Source: Our World in Data (OWID)

Original dataset:
https://github.com/owid/covid-19-data

Downloaded: 17 November 2026

This dataset contains 429,435 rows and was converted
from CSV to Parquet v2 using DuckDB.

Compression results:
- CSV: 98.39 MB
- Snappy: 13.93 MB
- ZSTD: 10.64 MB

ZSTD was selected because it reduced the file size by 89.2%.

This dataset is used for a Malloy assignment.
